# Build a Score Studio workflow

Load the `score-studio-workflow` skill.

Discover the current workflow block catalog from the API or repository before
writing a definition. Specify nodes, typed edges, required configuration,
expected outputs, and runtime class for each block. Add evaluation or conformity
gates before deployment, and monitoring plus captured-sample feedback after it.

Validate the definition with the current API or schema. If execution returns
preview mode or deferred blocks, explain exactly what executed and what requires
a connected provider or later workload.
